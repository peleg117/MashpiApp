# Mashpi — מאגר משפיענים ויוצרי תוכן

אפליקציית ווב למשרדי פרסום וסוכנויות דיגיטל: דאטה סנטר של משפיענים ויוצרי תוכן, עם חיפוש חכם בעברית ועדכון נתונים בזמן אמת.

## מה יש באפליקציה

- **חיפוש חכם בשפה חופשית.** כותבים את הצורך כמו שמדברים, והמערכת מתרגמת אותו לסינונים:
  - `משפיענית אמא מעל 50,000 עוקבים` → נשים · אמהות והורות · מעל 50K
  - `יוצרי תוכן אוכל בטיקטוק בין 10K ל-100K`
  - `מיקרו משפיעניות ביוטי מתל אביב`
  - `כושר באינסטגרם מעורבות מעל 4%`
- **סינון מדויק** לפי פלטפורמה, קטגוריה (18 תחומים), מגדר, טווח עוקבים / דרגה (ננו, מיקרו, מאקרו, מגה), אחוז מעורבות ועיר.
- **מיון** לפי עוקבים, מעורבות, צמיחה ב-30 הימים האחרונים ותאריך עדכון.
- **כרטיס משפיען** עם גרף עוקבים ל-90 יום, פרטי קשר, הערות פנימיות ומקור הנתונים.
- **עדכונים בלייב.** מנגנון סנכרון ברקע מושך נתונים עדכניים מה-APIs של הרשתות, ושולח כל שינוי מיד לכל הדפדפנים הפתוחים (Server-Sent Events). שורות שמתעדכנות מהבהבות, ופיד "עדכונים בזמן אמת" מציג את השינויים.
- **הוספת משפיען לפי לינק.** מדביקים לינק לפרופיל, הפלטפורמה ושם המשתמש מזוהים אוטומטית, ואם יש מקור נתונים מחובר, המספרים נמשכים מיד.
- **ייבוא מ-CSV** (כותרות בעברית או באנגלית) ו**ייצוא לאקסל** של תוצאות החיפוש.
- ממשק בעברית (RTL), מותאם למובייל ולמצב כהה.

## הפעלה מהירה

דרוש Node.js בגרסה 22.13 ומעלה (המסד מבוסס על SQLite המובנה ב-Node, כך שאין צורך בהתקנת מסד נתונים).

```bash
npm install
npm start
# http://localhost:3000
```

בהפעלה הראשונה המאגר מתמלא ב-150 משפיענים **בדיוניים** לדוגמה, מסומנים בתג "דמו". הנתונים שלהם משתנים בסימולציה כדי שאפשר יהיה לראות את העדכונים בלייב. כדי להתחיל עם מאגר ריק: `SEED_DEMO_DATA=false`. כדי למחוק את הדמו וליצור אותו מחדש: `npm run seed`.

הגדרות נוספות מפורטות ב-`.env.example` (מעתיקים אותו ל-`.env`).

## חיבור מקורות נתונים אמיתיים (עדכון בלייב)

לכל פלטפורמה יש "ספק נתונים". כשמוגדרים מפתחות API, מנגנון הסנכרון מעדכן אוטומטית כל פרופיל שהנתונים שלו ישנים מ-`SYNC_STALE_MINUTES` (ברירת מחדל: 6 שעות). פרופיל של פלטפורמה בלי ספק מוגדר מסומן "עדכון ידני".

| פלטפורמה | מה צריך | הערות |
|---|---|---|
| **YouTube** | `YOUTUBE_API_KEY` מ-Google Cloud Console (YouTube Data API v3) | הכי פשוט להגדרה, חינם במכסה סבירה. מושך מנויים, מספר סרטונים וצפיות ממוצעות. |
| **Instagram** | `INSTAGRAM_ACCESS_TOKEN` + `INSTAGRAM_BUSINESS_ACCOUNT_ID` (Instagram Graph API, Business Discovery) | עובד רק על חשבונות **עסקיים / קריאייטור**, וזה רוב המשפיענים. מחשב גם אחוז מעורבות מ-12 הפוסטים האחרונים. |
| **TikTok** | `TIKTOK_CLIENT_KEY` + `TIKTOK_CLIENT_SECRET` (TikTok Research API) | דורש אישור גישה מטיקטוק. |
| Facebook / X | — | כרגע עדכון ידני או דרך ייבוא CSV. |

> **הערה חשובה:** גריפת נתונים (scraping) מאינסטגרם או מטיקטוק בלי API רשמי מפרה את תנאי השימוש שלהן. אם צריך כיסוי רחב יותר מה-APIs הרשמיים, הדרך המקובלת היא ספק דאטה מסחרי (למשל Modash, HypeAuditor או Phyllo). מוסיפים אותו כספק נוסף ב-`src/providers/` עם אותו ממשק `fetchProfile`.

## אבטחה

כשמגדירים `ADMIN_TOKEN`, כל פעולות הכתיבה (הוספה, עריכה, מחיקה, ייבוא ורענון) דורשות את הטוקן, והדפדפן מבקש אותו בפעם הראשונה. חיפוש וצפייה פתוחים לכל מי שיש לו גישה לשרת, ולכן מומלץ להריץ מאחורי VPN או מערכת התחברות של הארגון. ניהול משתמשים מלא מופיע ברשימת הצעדים הבאים.

## API

| שיטה | נתיב | תיאור |
|---|---|---|
| GET | `/api/influencers` | חיפוש. פרמטרים: `smart` (טקסט חופשי), `q`, `platform`, `category`, `gender`, `tier`, `minFollowers`, `maxFollowers`, `minEngagement`, `city`, `sort`, `order`, `page`, `pageSize` |
| GET | `/api/influencers/export.csv` | ייצוא תוצאות (אותם פרמטרים) |
| GET | `/api/influencers/:id` | משפיען + היסטוריית עוקבים |
| POST | `/api/influencers` | הוספה (מספיק `profile_url`) |
| PATCH / DELETE | `/api/influencers/:id` | עריכה / מחיקה |
| POST | `/api/influencers/:id/refresh` | רענון נתונים מיידי |
| POST | `/api/import` | ייבוא CSV (גוף הבקשה: `text/csv`) |
| GET | `/api/parse?text=` | הצגת הפענוח של שאילתה חופשית |
| GET | `/api/events` | זרם עדכונים בזמן אמת (SSE) |
| GET | `/api/stats`, `/api/meta` | סטטיסטיקה ונתוני עזר |

## מבנה הקוד

```
src/
  server.js        שרת Express + נתיבי API
  repository.js    גישה למסד: חיפוש, עדכון, היסטוריה
  queryParser.js   פענוח חיפוש חכם בעברית/אנגלית
  sync.js          מנגנון הסנכרון ברקע
  events.js        שידור עדכונים בזמן אמת (SSE)
  providers/       חיבורים ל-YouTube, Instagram, TikTok + סימולציית דמו
  categories.js    קטגוריות ודרגות עוקבים
  platforms.js     זיהוי לינקים לפרופילים
  csv.js           ייבוא/ייצוא CSV
  seed.js          יצירת נתוני דמו
public/            ממשק המשתמש (HTML/CSS/JS, בלי שלב build)
test/              בדיקות (npm test)
```

## צעדים הבאים מומלצים

- התחברות משתמשים והרשאות לפי סוכנות או צוות
- רשימות שמורות ("שורטליסט לקמפיין") ושיתוף שלהן עם לקוחות
- נתוני קהל (גיל, מיקום ומגדר של העוקבים) דרך ספק דאטה מסחרי
- התראות על משפיענים חדשים שעונים על חיפוש שמור
